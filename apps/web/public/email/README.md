# `public/email/` — 이메일 전용 정적 자산

이메일 HTML 이 참조하는 이미지를 둔다. **여기 파일명은 절대 바꾸지 않는다.**

## 왜 `public/` 인가

Vite 는 `src/assets/` 의 이미지를 빌드하면서 콘텐츠 해시를 붙인다
(`logo-DzD3LiEJ.webp`). 웹에서는 캐시 무효화에 유리하지만 **이메일에서는 치명적**이다 —
이미 발송된 메일은 되돌릴 수 없는데 다음 배포에 파일명이 바뀌면 **과거 발송분의 이미지가
전부 깨진다.** 메일은 몇 년을 산다.

`public/` 은 해시 없이 그대로 복사되므로 URL 이 영구히 고정된다.

## 규칙

- **PNG 또는 JPG 만.** `.svg` 는 Gmail·Outlook·Apple Mail 이 사실상 지원하지 않고,
  `.webp` 는 Outlook 이 지원하지 않는다.
- **표시 크기의 3배 해상도**로 넣고 HTML 에서 `width`/`height` 속성으로 축소한다
  (속성이 없으면 Outlook 이 레이아웃을 못 잡는다).
- **파일명 변경·삭제 금지.** 참조 중인 메일이 이미 나가 있다.
- 이미지는 다수 클라이언트에서 **기본 차단**된다. 핵심 정보를 이미지에 넣지 말 것.

## 파일

| 파일 | 용도 | 비고 |
|---|---|---|
| `havit-logo.png` | 전 이메일 공통 헤더 로고 (360×239, 표시 120×80) | **흰 배경을 구워 넣었다.** 투명이면 어두운 워드마크(#121212)가 다크모드 카드 위에서 사라진다. 다크모드 이미지 스왑은 Gmail 에서 동작하지 않아 쓸 수 없다 |
| `havit-logo-source.svg` | 위 PNG 의 원본 벡터 | 참조용. **이메일에서 직접 링크 금지** |
